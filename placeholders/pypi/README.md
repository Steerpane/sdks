# steerpane

This name is held by the Steerpane project so nobody else can use it. It contains no code you need.

The Python client is `steerpane-sdk`, and it imports as `steerpane`:

```bash
pip uninstall steerpane
pip install steerpane-sdk
```

This placeholder installs only an empty `steerpane_placeholder` module, so it doesn't clash with that import.

More at https://steerpane.app
